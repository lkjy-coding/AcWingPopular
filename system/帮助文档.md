**1.显示大片空白怎么办？**

请确认：

- 网络是否畅通？
- 当前是否能够连接到 GitHub？**此问题多半是因为当前网络无法连接到 GitHub 导致的渲染失败。**
- 是否支持下载在线文件？
- 当前内存（RAM/ROM，**尤其是 ROM**）是否充足且可用？

解决方案：

- 使用其他网络，或使用热点网络、移动网络、蜂窝网络。
- 排查路由器问题，检查路由器是否正常工作。
- 检查网关、DNS等是否配置成功且正确。
- 如果有使用代理工具等，请关闭；如果没有，可以尝试打开。

::::warning[请注意合规性]

本站不提倡用户违反中国（及当地）的网络管理等法律，使用加速器等网络工具时，您应当知晓其后果，明白其的（潜在）违法性质，并在法律允许的范围内承担全部责任。

::::

- 检查当前内存（RAM/ROM，**尤其是 ROM**）是否充足且可用，如果充足请略过，如果不充足，尝试清理后台、清除某些不必要的文件。
- 尝试`ping https://github.com/`。
- 检查浏览器、网络策略的某些设置。
- **也有可能图片真挂了，届时请查看 GitHub 仓库（lkjy-coding/AcWingPopular）对应页面的 .MD 文件下是否仍然存在图片。**

**2.显示大片乱码怎么办？**

请选择正确的字库。如 UTF-8。

**2. What should I do if a large area of garbled text appears?**

Please select the correct character encoding. For example, UTF-8.
