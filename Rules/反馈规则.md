# 反馈规则

::::warning[一并阅读]

请一并阅读[条目反馈规则](https://lkjy-coding.github.io/AcWingPopular.html#Rules%2F%E6%9D%A1%E7%9B%AE%E5%8F%8D%E9%A6%88%E8%A7%84%E5%88%99.md)。

::::

::::warning[请认真阅读规则再反馈]

请先将此规则仔细阅读，确认无误后再反馈。如您违反规则反馈，很有可能导致：

- 反馈不受理
- 被加入黑名单
- 被举报
- 被警告
- 被公示
- 其他可能的后果

::::

::::warning[请选择正确的平台]

目前**仅接受来自 AcWing 的反馈**，其他渠道反馈有极大概率不受理。

::::

::::pro[自查]

如果你的反馈没有被受理，请检查：

1. 是否选错了平台？
2. 反馈是否合规？
3. 问题是否仍然存在？
4. 描述是否恰当全面？
5. 是否向错误的用户进行了反馈？
6. **是否被 lkjy 拉黑？**
7. 是否已绑定手机号？
8. 账号是否可以正常使用？
9. 是否才反馈不久，或时间点是否过早/过晚？
10. 是否正在被处理？
11. lkjy 此时是否有空处理？**（这个是 lkjy 自己的事情，放在这里只是提示一下）**

::::

在反馈时，请给 [lkjy](https://www.acwing.com/user/myspace/record/504862/) 提交你的反馈、资料。

## 反馈类型

你可以提交以下反馈：

1. 对“待补充”内容的考证/补充
2. 对条目中出错处的纠正/报告
3. 对注释内容/资料的补充/勘误
4. 对平台BUG的反馈
5. 对新功能的想法/建议
6. 对条目的补充（新增条目）

你**不应**提交以下反馈：

::::warning[请勿违规]

提交以下反馈可能构成违规，依据本规则进行处理。

::::

1. 对 AcWing 账号的操作
2. GitHub OAuth/AcWing 账号登录等
3. 评论等社交功能
4. GitHub Issues **（极可能不予受理）**
5. 对反馈的催促
6. 在其他平台 *（如洛谷、博客园、CSDN等）*（的）反馈
7. GitHub Actions
8. 其他无关的、不当的反馈

## 反馈渠道

目前**仅接受以下渠道**：

1. AC Chat（[不支持直链，仅分享个人中心](https://www.acwing.com/user/myspace/record/504862/)）
2. AcWing 评论区（[帖子](https://www.acwing.com/file_system/file/content/whole/index/content/14385238/)）

因此，**你至少需要一个已绑定手机号且能正常使用的 AcWing 账号以反馈。**

## 反馈须知

1. 你应当在反馈时友善待人，而非恶语相向。
2. 不应过分催促，修 BUG 也是要时间的。
3. 如果你被拉黑了，你可以委托别人帮忙提交，**或者根本不去提交。**
4. 不要找 lkjy 给你的 AcWing 账号绑定手机号、解封什么的，lkjy 没有权限。
5. 优先去找 [yxc](https://www.acwing.com/user/myspace/record/1/) 解决你在 AcWing 的问题。
6. 先看看是不是你的环境、网络、平台出了问题，lkjy 一般不给特定的适配版本。
7. 如果可以，**最好配上 F12（开发者模式）的报告。**
8. **如果发生了崩溃类问题，一定要尽可能的提供日志！没有日志很难定位到问题！**
9. 如果你是 HTML/JavaScript 大佬，你也可以去 lkjy-coding.github.io **仓库**中，找到以下文件：
    - `build-files.js`
    - `build-files.yml`
    - `AcWingPopular.html`
   
   这些是本站的依赖文件，你可以自行捉虫。

    *当然，日后也会在 AcWingPopular **仓库**里加上一些 workflow 以提升加载速度的。*
11. 你可以去仓库的 **Actions** 标签页看看是不是有灰色的叹号（Cancelled）和红色的叉号（Error）。
12. *“今天 GitHub 是不是又崩溃了？？？！！！”*

     ↑试着访问 GitHub 看看还健在吗
14. lkjy 对此规则拥有最终解释权，以及实时修订的权利。有新版本发布后，自动依据新版本执行。
